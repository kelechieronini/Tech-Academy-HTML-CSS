Before learning about float and grid, I mostly understood CSS as a way to style a webpage, mainly colours, fonts, and borders. Now I have learnt that CSS can also control how elements are arranged on a page, which changed how I think about layout design. Two important concepts I picked up are the float property and CSS Grid.

The float property is used to push an element to the left or right side of its container. A common use of float is to make text wrap around an image. If an image is floated to the left, the text that follows it flows around the right side of the image, and the same thing happens in reverse if the image is floated right instead. I also learnt that float can be used with block level elements like divs, not just images, which makes it possible to create simple multi column layouts as well. Once an element is floated, it is taken out of the normal flow of the document, so other elements can move around it as if it were not there in the usual sense.

Another thing I now understand about float is the clear property. Clear is useful when you want an element to stop flowing around a floated element, and it can be set to left, right, or both depending on where the floating is coming from. I also learnt about the clearfix technique. This is used when a container holding floated elements has its height collapse, since the floated elements are no longer part of the normal document flow and the container does not account for their space. Clearfix helps the container properly contain its floated content so the layout does not break or overlap with the content that comes after it.

I also learnt about CSS Grid, which is a more structured and modern way to build layouts. A grid is made up of rows and columns, and it allows elements to be placed in different parts of a webpage with much more precision than float allows. To create a grid, the container is given display: grid, and its direct children automatically become grid items. grid template columns can define the number and size of columns, while grid template rows does the same for rows, giving a clear structure to work with from the start.

I learnt different ways of sizing grid columns and rows too. Pixel values and percentages both work, but the fraction unit, written as fr, is especially useful for creating responsive layouts. For example, if a grid has four fractions, one fraction represents one quarter of the available space, and the columns adjust automatically as the screen size changes. The repeat function also makes writing grid layouts easier by repeating a column or row size instead of typing it out multiple times, which keeps the code shorter and easier to read.

Another useful feature is the minmax function, which lets a grid item have a minimum and maximum size. This makes layouts more responsive as the browser window changes size, since the item will not shrink below the minimum or grow past the maximum. I also learnt about grid gap, which creates space between rows and columns without needing extra margin on individual items.

Finally, I learnt that grid items can span across multiple columns or rows using properties like grid column, grid row, and grid area. CSS Grid also has grid template areas, which makes it possible to name sections such as header, sidebar, content, and footer and arrange them clearly and visually within the code itself, making the layout easier to understand at a glance.

Overall, I learnt that float is useful for simple positioning and wrapping, especially around images, while CSS Grid provides a more powerful and organized way to build complete webpage layouts. Learning both has given me a better sense of when to reach for a simple solution and when a full layout system like Grid is the better choice.
